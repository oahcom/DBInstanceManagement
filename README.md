# DBInstanceManagement
一个笔试题，## 方案 A：数据库实例管理系统 ### 使用技术栈： python, django, celery ### 笔试题目： 1. 设计一个数据库实例管理系统，用于管理企业内部的数据库实例，包含实例、集群、部门等 模型 2. 提供对应模型的增删改查接口；提供一个 API，用于探测某个实例是否 TCP 端口可达 3. 需维护每个实例的账号密码，每隔 12 小时随机轮换每个实例的密码并加密记录 4. 每天 00:00 按部门和集群维度统计实例数量，并把统计数据写入数据库 5. 实现一个中间件，统计每个请求的请求耗时 ### 提交方式： 1. 使用 git 提交代码到 github 或者 gitee，提交对应代码仓库的地址。
